# Router comparison, 2026-09-23

Same 36 prompts (`evals/prompts.jsonl`), same three questions and rules (`src/trivium/targets.yaml`
at this commit), confidence thresholds off (`min_confidence: {}`) so every router is judged on its
first choice.

**Machine:** Apple M5 Pro, 48 GB, macOS. **Runtimes:** semif at commit `1f2dea3` with MLX 0.32.2,
Qwen3.5-4B at revision `851bf6e`, bf16. Laya 0.3.7 from PyPI on PyTorch MPS.

| Router | Kind | Difficulty | Tools | Right target | p50 | p90 |
|---|---|---|---|---|---|---|
| semif + Qwen3.5-4B | 94.4% | 80.6% | 80.6% | 80.6% | 241 ms | 243 ms |
| Laya, English checkpoint | 69.4% | 47.2% | 97.2% | 38.9% | 98 ms | 115 ms |
| Laya, English, original difficulty wording | 69.4% | 50.0% | 97.2% | 41.7% | 102 ms | 114 ms |
| Laya, typed-decisions checkpoint | 80.6% | 47.2% | 100% | 47.2% | 99 ms | 117 ms |

With the default thresholds (tuned for semif), semif scores 80.6% right target with 2.8% of prompts
sent to the fallback. Laya English scores 41.7% with 27.8% sent to the fallback: its probabilities are
flatter, so semif's thresholds do not fit it.

## Observations

- Laya answers "moderate" to nearly every difficulty question (probabilities around 0.45-0.65), so the
  easy-to-local and hard-to-frontier rules almost never fire for it.
- Laya's English checkpoint reads chat-style requests as code: "rewrite this sentence to sound less
  formal" became `code_change` at 0.83, "write the changelog entry" at 0.86.
- Laya is the better judge of the yes/no `tools` question (97-100% against semif's 81-83%). A hybrid
  that asks Laya about tools and semif about kind and difficulty is an obvious next experiment.
- Laya loaded with a warning that its English checkpoint ships an out-of-range temperature for
  choice questions with 11+ options (clamped to 0.5). None of these questions has more than 6 options.
- Caveats: 36 prompts, one labeller, and the question wording was tuned on this set with semif. Laya's
  own documentation says it is meant to be fine-tuned before production use; none of this tests a
  fine-tuned Laya.

Fitted temperatures (`ask calibrate`, grid 0.25 to 9.8):

| Backend | kind | difficulty | tools |
|---|---|---|---|
| semif | 0.59 (sharpen) | 1.37 (soften) | 2.17 (soften) |
| Laya English | 1.09 | 0.93 | 0.25, at the grid edge (sharpen) |
| Hybrid | 0.60 | 1.35 | 0.25, at the grid edge |

- semif is over-confident about difficulty and tools and slightly under-confident about kind.
  Laya is strongly under-confident about tools: right on 35 of 36 prompts while reporting a median
  confidence of 0.75 on those (range 0.51 to 0.96).
- The default `min_confidence` values were tuned on semif's raw scores. With Laya's flatter tools
  scores the hybrid sends 13.9% of prompts to the fallback, and calibrating semif without re-tuning
  the thresholds costs 5.6 points of right targets. Thresholds must be chosen after calibration.
- The tools accuracy for semif (80.6% here, 83.3% in the first table) differs by one prompt between
  runs of the same questions, consistent with the bf16 variation semif documents.
- All temperatures are fitted and evaluated on the same 36 prompts. They show direction, not values to ship.

## Follow-up, 2026-09-25: Laya evidence order, typed-decisions hybrid, threshold sweep

**Evidence order.** Laya reads about 320 tokens of state and cuts the end. Putting the repository
sentence before the prompt fixed long prompts but dropped Laya English on the tools question from
35/36 to 26/36 on this set. Keeping the order and clipping the request to 300 characters (head and
tail) keeps 35/36 here (no prompt in this set is longer than 147 characters) and lets the sentence
through on long prompts:

| Laya English, p(workspace) | 60-line log, in repo / outside | 40-frame traceback, in repo / outside |
|---|---|---|
| Request first, unclipped (original) | 0.15 / 0.15 | not measured |
| Context first | 0.64 / 0.09 | not measured |
| Request first, clipped to 300 chars (shipped) | 0.60 / 0.08 | 0.72 / 0.45 |
| clipped to 500 / 700 / 900 chars, log | 0.58 / 0.14, 0.45 / 0.13, 0.36 / 0.10 | 0.41 / 0.32, 0.65 / 0.35, 0.49 / 0.32 |

The two long prompts are made up; the clip length is a starting point, not a measurement.

**Hybrid with the typed-decisions checkpoint** (now the default `laya_subfolder`):

| Hybrid | Tools | Right target, thresholds off | Right target, default thresholds | Fallback, default thresholds | p50 |
|---|---|---|---|---|---|
| Laya English for tools | 97.2% | 83.3% | 80.6% | 13.9% | 250 ms |
| Laya typed-decisions for tools | 100% | 83.3% | 80.6% | 8.3% | 247 ms |

**Threshold sweep** (`ask eval --sweep`, one floor for every question, uncalibrated):

| Floor | semif right / fallback | Hybrid English right / fallback | Hybrid typed-decisions right / fallback |
|---|---|---|---|
| 0.00 | 80.6% / 0% | 83.3% / 0% | 83.3% / 0% |
| 0.50 | 80.6% / 5.6% | 83.3% / 5.6% | 83.3% / 5.6% |
| 0.55 | 86.1% / 11.1% | 86.1% / 19.4% | 86.1% / 13.9% |
| 0.60 | 80.6% / 22.2% | 83.3% / 33.3% | 83.3% / 22.2% |
| 0.70 | 75.0% / 41.7% | 61.1% / 58.3% | 58.3% / 61.1% |

Accuracy among the prompts that were not sent to the fallback rises with the floor (semif 80.6% at
0.00 to about 90% at 0.65 to 0.70), so the scores carry real signal. The 0.55 peak is in-sample on
36 prompts; the shipped floors are unchanged.

## Packaging parity, 2026-09-25

Trivium now vendors semif (commit 1f2dea3) and installs mlx-lm 0.31.3 from PyPI instead of semif's
git pin of mlx-lm (0.32.0 dev, which carries an upstream Qwen fix). Laya moved from 0.3.7, since removed
from PyPI, to 0.3.20, with its weights pinned to Hugging Face revision 55cf4c4 (all 21 weight and config
files identical to the revision used on 2026-09-23).

- Raw semif scores, git mlx-lm 0.32.0 vs PyPI 0.31.3, 36 prompts x 3 questions: no changed choice,
  no changed routing decision or fallback with the default thresholds. Largest probability change
  0.071, median 0.0004; 4 of 108 question scores moved by more than 0.05.
- Every accuracy, right-target and fallback figure in this file reproduced exactly on the new stack
  (semif, Laya English and typed-decisions, both hybrids, thresholds off and on).
